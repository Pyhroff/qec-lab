NOISE MODEL
Shot simulation uses code-capacity noise: each data qubit independently suffers X or Z error with probability p. No measurement errors.

Threshold curve uses circuit-level noise via Stim: after_clifford_depolarization=p throughout the full syndrome extraction circuit including ancilla prep/measurement. This is the standard model in surface code literature (threshold ~ 0.5–1%).
